# ActividadesAbstracfaces
Una página para la tarea UD5 T3 de la asignatura de PRO en el cual hacemos 
2 apartados.

1º apartado:
    En este apartado montamos el fichero Figura2d en el cual defino unicamente 
    2 operaciones vacias las cuales se modifican segun la figura que en este caso 
    son el rectangulo y el circulo en el cual se le pasan los datos necesarios de cada
    figura por consola.

2º apartado:
    En este apartado montamos una clase Abstracta llamada vehiculo que luego extendemos en
    la clase CocheCombustion y añadimos litro combustible para que el motor necesite combustible
    para arrancar y motorEncendido para declarar ese valor como un booleano de si "esta arrancado"
    no "no esta arrancado".
